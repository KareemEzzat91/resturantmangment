## Recommended README Layout

For the main README, group screenshots by user journey rather than listing every screen in one long gallery:

1. Authentication
2. Restaurant Discovery
3. Menu & Reservation
4. Payment
5. Account & Notifications
6. Administration

After screenshots are uploaded to GitHub, replace each `SCREENSHOT_URL` placeholder in `README.md` with its corresponding image URL.
