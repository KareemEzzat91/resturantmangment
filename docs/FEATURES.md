# Feature Map

## Customer

| Area | Capabilities |
|---|---|
| Authentication | Login, registration, forgot password |
| Discovery | Restaurants, branches, ratings, locations |
| Menu | Food items, categories, meal schedules |
| Reservations | Tables, dates, schedules, guest information |
| Payments | Payment flow and transaction history |
| Account | Profile, favorites, notifications |

## Administration

| Area | Capabilities |
|---|---|
| Restaurant | Restaurant-level administration and statistics |
| Branches | Create, update, delete, and assign branch admins |
| Staff | Chef profiles and staff information |
| Tables | Capacity and availability management |
| Menus | Menu and food-item administration |
| Schedules | Branch and meal scheduling |

## Platform

- REST API integration
- Bearer-token authentication
- Persistent local session state
- Cubit/BLoC state management
- Google Maps integration
- Loading and error feedback
- Image selection and network image support
- Animated navigation and UI components
